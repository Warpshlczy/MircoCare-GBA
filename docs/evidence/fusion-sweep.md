# fusion-sweep · 权重扫描与阈值校准记录

> 对应 `docs/dev.md` §4.4 C1 的交付项。数据源：`docs/REPORT-2026-10-23-实测结果.md`；脚本：`backend/scripts/eval_fusion.py`。
> **结论先说：两流权重/阈值有实测扫描；三流行为流没有配对标签，未做 AUC 回算，当前 0.15/0.65/0.20 是初始先验。**

## 1. 两流（声学 / 语义）权重扫描

数据集：单一中文阿尔茨海默语音数据集，322 名被试（AD 与 MCI 均归为阳性），回顾性分析。

| 声学 : 语义 | 融合 AUC |
|---|---|
| 0.0 : 1.0 | 0.708 |
| **0.2 : 0.8** | **0.717** |
| 0.3 : 0.7 | 0.717 |
| 0.4 : 0.6 | 0.708 |
| 0.5 : 0.5 | 0.699 |
| 0.6 : 0.4 | 0.687 |
| 0.8 : 0.2 | 0.652 |
| 1.0 : 0.0 | 0.616 |

**选定 0.2 / 0.8**：与 0.3/0.7 并列最高，取更偏向语义流的一侧（声学单流 CV5 AUC 仅 0.604，交叉拟合 0.616；语义流 0.708 / LOO 0.698）。

## 2. 阈值校准

| 阈值 | 取值 | 依据 |
|---|---|---|
| watch | **0.409** | 对照组分数 40 分位 |
| elevated | **0.521** | 对照组分数 65 分位 |

对应 watch 敏感度 **0.863**、特异性 **0.396**（筛查取向的高敏感低特异取舍）。elevated 层才建议就医。

## 3. 三流（+ 行为）的处理

- 初始先验：**0.15 / 0.65 / 0.20**，与 `docs/dev.md` §4.4 C1 一致；已写入 `config.py` 的 `fusion3_w_*`。
- **没有做三流 AUC 扫描**，原因：322 人数据集只有声学/语义两流标签，没有配对的 `BehaviourDaily`（行为数据来自另一类居家监测场景）；在行为流上没有真实标签时做「扫描」只会得到伪最优。
- **回归保护已实现**：行为流缺失时，融合逐位回到校准后的两流 **0.2 / 0.8**，历史分层不漂移（`selfcheck.py` 断言 `0.2*ac + 0.8*sem`）。
- **单流降级已实现**：仅剩一个流 → 强制 `low` + `insufficientStreams: true`。

**因此 §4.4 的「AUC 不低于两流基线 0.717 的 0.98 倍」在这份数据上不可验证**，状态记为 **N/A（无行为标签）**，而不是「通过」。

## 4. 复现方式

```bash
cd backend
AURA_ACOUSTIC_MODEL=./models/acoustic_lgbm.txt \
AURA_SEMANTIC_MODEL=./models/semantic_lr.joblib \
python scripts/eval_fusion.py
# 输出：models/fusion_eval_report.json（AUC / 阈值建议 / 分位）
```

三流复现（仅验证代码路径，不产出 AUC）：

```bash
AURA_LLM_ENABLED=false python selfcheck.py   # 三流权重、缺流回归、单流降级
```

## 5. 下一步（需前瞻队列）

1. 招募 ≥300 人前瞻队列，采集同日 `BehaviourDaily` + 语音样本；
2. 以「敏感度 ≥0.80」为约束，在 0.0–0.4 行为权重网格上最大化特异性；
3. 记录每个网格点的 AUC / 敏感度 / 特异性，用 k≥20 的聚合口径发布；
4. 结果回填本文件，并递增 `FUSION_VERSION`（当前 `latefusion-v3`）；
5. 语义流移除 `mattr` 后重跑 `train_semantic_model.py` 与 `eval_fusion.py`（当前产物仍含 mattr，见附录 E.4 注记）。
