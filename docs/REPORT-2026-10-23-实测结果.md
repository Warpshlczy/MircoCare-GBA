## 2. CASAS 组间分析（T0-B 第 3 步）✅ 组间可分性显著

**样本**：400 人（dementia 36 / MCI 59 / 年龄对照 CTRL 164 / at-risk 30）
**脚本**：`D:\GBA-hackathon\scripts\casas_group_analysis.py` → `scripts/out/casas_features.csv` + `casas_group_report.json`

### 关键发现（注意：得分=错误计数，**越高越差**）

| 指标（中位数） | dementia | MCI | CTRL | 解读 |
|---|---|---|---|---|
| tasks_sum（8 任务错误总分） | **28.0** | 17.5 | 14.0 | 认知组任务错误显著多 |
| task2_score（服药分装） | **4.0** | 2.0 | 1.0 | **服药任务是最强单项** |
| dayout_accuracy（外出错误） | **26.0** | 14.0 | 12.0 | 复杂情境错误暴增 |
| dayout_sequencing（排序能力） | **1.5** | 4.0 | 4.0 | 排序能力塌陷（方向相反） |
| n_door_events（门交互） | **43.5** | 66.0 | 68.0 | 活动范围收窄 |
| n_item_events（物品交互） | **11.0** | 18.0 | 18.0 | 物品交互减少 |

### 效应量（Cliff's delta，|d|>0.474 为大）

| 对比 | 最强指标 | delta | p |
|---|---|---|---|
| dementia vs CTRL | dayout_accuracy | **+0.989** | <0.0001 |
| | task2（服药） | +0.817 | <0.0001 |
| | dayout_sequencing | -0.725 | 0.002 |
| | n_door_events | -0.603 | <0.0001 |
| MCI vs CTRL | tasks_sum | **+0.424** | <0.0001 |
| | dayout_accuracy | +0.404 | 0.0002 |
| | task2（服药） | +0.362 | <0.0001 |
| dementia vs MCI | dayout_accuracy | +0.898 | 0.0005 |
| | n_door_events | -0.641 | <0.0001 |

**三条可讲的结论**：
1. **任务执行质量可分组**，且 MCI 与对照已可分（tasks_sum delta=0.42）——「行为变化检测」在这份数据上有地基
2. **服药任务（task2）是所有单项里最强的**——直接支撑 T1「前瞻记忆/习惯坚持」点位（PLAN §4），App 的食药提醒模块就是它的手机化形态
3. **传感器侧信号方向明确**：认知组门/物品交互减少、外出任务排序塌陷——X-BCD 的「简化/碎片化」模式在这份数据上肉眼可见
